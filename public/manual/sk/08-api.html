API a integrácie

Zoad ponúka REST API pre vlastné integrácie a napojenie na automatizačné nástroje, a MCP server pre AI asistentov.

Osobné prístupové tokeny

Nastavenia → API tokeny → Vytvoriť token vygeneruje token na prihlásenie do API bez použitia hesla. Pri vytváraní vyberieš, k čomu má token prístup (napr. len na čítanie faktúr) — token má vždy len taký rozsah oprávnení, aký mu prideľuješ, nikdy viac, než má samotný účet.

Token sa v plnom znení zobrazí len raz, hneď po vytvorení. Ulož si ho bezpečne — pri strate treba vytvoriť nový a starý zrušiť.

Zoznam existujúcich tokenov (bez ich hodnoty) nájdeš na tej istej stránke; nepoužívaný alebo kompromitovaný token vieš okamžite zrušiť.

Dokumentácia API

Kompletná referencia všetkých endpointov (parametre, návratové formáty, chybové stavy) je publikovaná ako OpenAPI dokumentácia na /api/documentation. Dokumentácia je generovaná priamo z kódu API, takže je vždy aktuálna.

Webhooky

Ak chceš byť o udalostiach v účte (napr. nová platba, vystavená faktúra) informovaný v reálnom čase vo vlastnom systéme namiesto pravidelného dopytovania API, nastav si webhook — Integrácie → Webhooky → Pridať endpoint:

  1. Zadaj cieľovú URL adresu, na ktorú má aplikácia posielať notifikácie.
  2. Vyber, na ktoré udalosti sa má endpoint prihlásiť.
  3. Ulož si vygenerovaný podpisový kľúč (secret) — každá doručená notifikácia je ním podpísaná, aby si na svojej strane vedel overiť, že správa naozaj prišla z Zoad.

Testovanie a história doručení

Tlačidlo Test pošle na endpoint skúšobnú notifikáciu bez čakania na reálnu udalosť — over si takto, že endpoint je dostupný, ešte pred ostrým nasadením. História pokusov o doručenie (úspešné aj neúspešné, vrátane HTTP stavu odpovede) je dostupná pri každom endpointe; endpoint s dlhodobo zlyhávajúcim doručovaním sa po prekročení limitu opakovaných chýb automaticky deaktivuje, aby neblokoval frontu.

MCP server pre AI asistentov

Zoad vystavuje aj MCP (Model Context Protocol) server, ktorý umožňuje AI asistentom (napr. Claude) pracovať s tvojimi dátami v Zoad priamo v rámci konverzácie — napríklad vypýtať si prehľad neuhradených faktúr alebo pripraviť podklady k dokladu, bez prepínania do aplikácie. Pripojenie k MCP serveru sa autentifikuje rovnakým prístupovým tokenom ako REST API a rešpektuje rovnaký rozsah oprávnení.

Konektory (Zapier/Make)

Keďže REST API je verejne zdokumentované a autentifikuje sa štandardnými tokenmi, dá sa napojiť aj na nízko-kódové automatizačné nástroje typu Zapier alebo Make bez nutnosti písať vlastný kód — ide o tú istú sadu endpointov ako pri priamej API integrácii.
