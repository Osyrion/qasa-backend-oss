API a integrace

Zoad nabízí REST API pro vlastní integrace a napojení na automatizační nástroje, a MCP server pro AI asistenty.

Osobní přístupové tokeny

Nastavení → API tokeny → Vytvořit token vygeneruje token pro přihlášení do API bez použití hesla. Při vytváření vybereš, k čemu má token přístup (např. jen ke čtení faktur) — token má vždy jen takový rozsah oprávnění, jaký mu přiděluješ, nikdy víc, než má samotný účet.

Token se v plném znění zobrazí jen jednou, hned po vytvoření. Ulož si ho bezpečně — při ztrátě je třeba vytvořit nový a starý zrušit.

Seznam existujících tokenů (bez jejich hodnoty) najdeš na stejné stránce; nepoužívaný nebo kompromitovaný token můžeš okamžitě zrušit.

Dokumentace API

Kompletní reference všech endpointů (parametry, návratové formáty, chybové stavy) je publikovaná jako OpenAPI dokumentace na /api/documentation. Dokumentace je generovaná přímo z kódu API, takže je vždy aktuální.

Webhooky

Pokud chceš být o událostech v účtu (např. nová platba, vystavená faktura) informován v reálném čase ve vlastním systému místo pravidelného dotazování API, nastav si webhook — Integrace → Webhooky → Přidat endpoint:

  1. Zadej cílovou URL adresu, na kterou má aplikace posílat notifikace.
  2. Vyber, na které události se má endpoint přihlásit.
  3. Ulož si vygenerovaný podpisový klíč (secret) — každá doručená notifikace je jím podepsaná, abys na své straně ověřil, že zpráva skutečně přišla z Zoad.

Testování a historie doručení

Tlačítko Test pošle na endpoint zkušební notifikaci bez čekání na reálnou událost — ověř si takto, že endpoint je dostupný, ještě před ostrým nasazením. Historie pokusů o doručení (úspěšné i neúspěšné, včetně HTTP stavu odpovědi) je dostupná u každého endpointu; endpoint s dlouhodobě selhávajícím doručováním se po překročení limitu opakovaných chyb automaticky deaktivuje, aby neblokoval frontu.

MCP server pro AI asistenty

Zoad vystavuje i MCP (Model Context Protocol) server, který umožňuje AI asistentům (např. Claude) pracovat s tvými daty v Zoad přímo v rámci konverzace — například vyžádat si přehled neuhrazených faktur nebo připravit podklady k dokladu, bez přepínání do aplikace. Připojení k MCP serveru se autentizuje stejným přístupovým tokenem jako REST API a respektuje stejný rozsah oprávnění.

Konektory (Zapier/Make)

Jelikož REST API je veřejně zdokumentované a autentizuje se standardními tokeny, dá se napojit i na nízkokódové automatizační nástroje typu Zapier nebo Make bez nutnosti psát vlastní kód — jde o stejnou sadu endpointů jako u přímé API integrace.
